# Marvel Comics Responsive Website

A responsive, Marvel-themed website designed to showcase superheroes with engaging visuals, character biographies, blog updates, and multimedia content.  
The project emphasizes **performance, creative design, and responsiveness**, delivering an immersive fan experience across devices.

---

## Features
- Fully responsive and mobile-friendly design for seamless browsing  
- Structured character biographies, blogs, and multimedia content  
- Built with **Bootstrap** for faster development and cross-device adaptability  
- Smooth and engaging user experience with optimized visuals  
- Successfully deployed on Netlify for public access  

---

## Technologies Used
- HTML5  
- CSS3  
- Bootstrap  
- JavaScript  
- Netlify (Deployment)
